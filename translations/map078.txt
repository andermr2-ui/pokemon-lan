[6|1|11|3]
ORIGINAL: Map connections are how two maps are displayed next to each other in the overworld, allowing you to walk from one to the other.
TRADUCCION:

[6|1|14|3]
ORIGINAL: The connections are defined in the PBS file "map_connections.txt". There is a Debug feature that makes connecting maps easier.
TRADUCCION:

[6|1|17|3]
ORIGINAL: In the Debug menu, go to "PBS File Editors..." > "Edit map_connections.txt". Instructions are available within. You can move maps around with the mouse.
TRADUCCION:

[6|1|23|3]
ORIGINAL: Every tile in a tileset has a terrain tag, which is a number. This number is used to give certain tiles special effects.
TRADUCCION:

[6|1|26|3]
ORIGINAL: For example, ledge tiles have terrain tag 1, which means the player jumps over them. Ledge tiles also have a single passable direction (set separately).
TRADUCCION:

[6|1|29|2]
ORIGINAL: Grass tiles (in which you can have wild encounters) have terrain tag 2. Water tiles have terrain tag 6 or 7.
TRADUCCION:

[6|1|31|3]
ORIGINAL: Terrain tag 0 means the tile has no special effect. See the wiki for more information and a complete list of all terrain tags and their effects.
TRADUCCION:

[6|1|34|3]
ORIGINAL: You can only set terrain tags up to 7 via RPG Maker XP's Database. Essentials has terrain tags with higher numbers.
TRADUCCION:

[6|1|37|3]
ORIGINAL: To fully set a tileset's terrain tags, open the Debug menu and go to "Other Editors..." > "Edit Terrain Tags".

[7|1|7|2]

TRADUCCION:

[7|1|9|3]
ORIGINAL: The party screen and Pokémon storage have a similar debug menu for modifying a Pokémon's properties, such as its level or species.
TRADUCCION:

[7|1|12|3]
ORIGINAL: You can use field moves at any time, and hold Ctrl to skip any battles and decide the outcome of Trainer battles. Hold Ctrl while moving to walk over anything.

[7|1|15|2]
